# Model dialect rules

Anima official guidance supports tags plus natural descriptions. Base, Aesthetic and Turbo are distinct variants; documented sampler, steps and CFG suggestions are external claims, not locally measured optima. Existing workflow filenames establish only a proposed binding. They do not establish downloaded model hashes or exact source reproduction.

Krea2 official prompting uses descriptive natural language. Expansion guidance prioritizes faithful subject, colors and relationships. This compiler preserves canonical traits and project constraints, without adding props. Native negative requirements block Krea workflows lacking that capability. No automatic natural-language substitute is authorized.

NovelAI braces, brackets and numeric :: emphasis are not portable. They are rejected in normalized descriptors rather than silently translated. Official NovelAI media concepts provide research context, not evidence of Anima or Krea model support.

The shared PromptSpec compiler produces model-specific syntax. Offline mining records retain NOT_RUN states, recipe and style fingerprints, source metadata and workflow binding. Runtime model recipes and the six MCP tools do not consume this candidate library. Explicit model selections and existing experimental opt-in remain enforced.

Pixel recipes describe candidate cluster/contour traits only. Logical resolution comes from project SOT; 768-pixel source images do not establish game pixel size. Direct pixel generation and nonpixel-source conversion require separate experiments and evidence.
