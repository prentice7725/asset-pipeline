## Grouping conclusions

- The explorer is **not mostly a set of clean base art styles**. A large part of it is camera/film/effect treatment. Those are separated so they do not pollute the game-art style menu.
- Animation is not one style: 90s cel, retro sci-fi, modern flat manga, kawaii/pop and dark/gothic anime are kept separately.
- Western cartoon is split from anime: rubber-hose/mascot language and flat angular/vector cartoon each get independent candidates.
- Painterly media are separated by medium: gouache, watercolor, engraving/woodcut, oil/impasto and folk/naive.
- Graphic print families are also separated: risograph/screenprint, punk-zine monochrome, vector/editorial and mixed-media collage.
- Genre direction is orthogonal but useful enough for model selection: cyberpunk, dark fantasy, dreamcore and retro airbrush each retain a representative candidate.
- Stylized 3D is represented by clay/toy and voxel/low-poly rather than photoreal 3D.

## Next empirical step

Do **not** generate all 1,596. Generate the 24 representatives under the same controlled character fixture first. For each candidate compare `anima_base_rebuilt`, `anima_turbo`, and `krea2_base`; select a primary model only from actual images. Where Base and Turbo behave similarly, collapse later rounds to the stronger Anima variant. This yields at most 72 first-pass cells and can be staged by family.

Recommended staging: (1) Animation + western cartoon, (2) storybook/painterly, (3) graphic/print, (4) genre + stylized 3D. Pixel remains HOLD.
