## Pixel64 비교 수용 기준

같은 **고해상도 원본** hash에서 baseline refiner / Fixer / 후보 후처리를 분기하고,
동일 native 64x64 출력·팔레트 조건과 사람의 실루엣·장비 식별성·수동 수정 시간을
각각 기록한다. 현재 64px 완제품에만 후처리해 생성 품질 개선을 주장하지 않는다.
대안 생성과 grid-conditioned 생성은 입력이 달라 별도 실험군이며 예산 승인이 필요하다.
실측값은 전부 NOT_MEASURED. 좋은 결과가 있을 때만 선택적 단계 연결을 검토한다.
