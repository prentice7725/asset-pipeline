# Manifest provenance

The runtime manifest is ../.codex-plugin/plugin.json and MCP wiring is ../.mcp.json.
Both follow the supported compatibility layout documented by OpenAI:
[Package your plugin](https://developers.openai.com/plugins/build/plugins).

The official Plugin Creator was unavailable in this session. This package was
authored from the fetched official manifest examples; local structural and skill
validation are separate from Creator validation. No registered ChatGPT app ID
or .app.json mapping has been invented. See ../../docs/plugin/STATUS.json.
