# Dependency and rights analysis

Existing bindings are Anima Base, Krea2 Turbo FP8, Anima Aesthetic v1.1 with Tomohi LoRA, and Anima Base with Pixelate x4 VAE. Names are filename observations only; exact installed hashes and compatibility with source examples remain unverified. Base, Aesthetic and Turbo recipes must never be interchanged solely because they share a model family. Tomohi requires explicit experimental selection; no missing dependency is downloaded automatically.

Anima official licensing distinguishes model/derivative terms from generated outputs. Krea repository Apache text does not automatically license local model weights. Each experiment requires weight, output and source-reference rights reviewed for its intended use. Unknown CivitAI creator licenses remain REVIEW_REQUIRED. No external image or raw prompt is copied into this library.

The local inventory report can establish filename presence and server reachability only. It establishes neither quality nor source reproduction. No new pixel/nonpixel production run or human image approval occurred in M2.6.
